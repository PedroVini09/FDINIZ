PROTEÇÃO DE DADOS PESSOAIS

Conformidade com a LGPD e segurança das informações

LEI GERAL DE PROTEÇÃO DE DADOS (LGPD)

A Lei nº 13.709/2018 (LGPD) estabelece regras sobre coleta, armazenamento, tratamento e compartilhamento de dados pessoais, garantindo maior proteção aos titulares.

Finalidade

Os dados são coletados para fins legítimos e informados.

Transparência

O titular tem acesso claro às informações sobre seus dados.

Necessidade

Apenas dados essenciais são tratados.

Segurança

Medidas técnicas protegem os dados contra acessos indevidos.

Direitos dos Titulares

  • Confirmação do tratamento
  • Acesso aos dados
  • Correção de dados
  • Anonimização ou exclusão
  • Portabilidade
  • Revogação do consentimento

Categorias de Dados

Dados Pessoais

Nome, CPF, telefone, e-mail, endereço, etc.

Dados Sensíveis

Religião, saúde, biometria, dados genéticos.

Dados Anonimizados

Dados que não permitem identificação do titular.
